## 快速开始

### 开发环境

```bash
# 安装依赖
pnpm install

# 启动开发服务器
make dev
```

### 生产构建

```bash
# 构建生产版本
make build
```

### 运行测试

```bash
# 前端单元测试
pnpm test
```
