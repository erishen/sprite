功能特性

为效率而生的桌面工具

📊

系统监控

实时显示 CPU、内存、硬盘、网络状态。最小化横条也能看到关键指标，负载过高时颜色预警。

🍅

番茄钟

自定义工作/休息时长，声音 + 系统通知提醒，每日完成统计，数据本地持久化。

🚀

快捷方式

JSON 配置网页、应用、脚本快捷方式。公开/私密配置分离，一键启动常用工具。

🤖

多 AI 后端

同时接入 Resolve Studio、Spring Harness、Resolve Harness 和内置 LLM。每个后端独立窗口，互不干扰。

📋

剪贴板历史

自动记录剪贴板历史，支持搜索和快速复制。所有数据本地存储，不上传任何服务器。

⚡

极致轻量

Tauri + Rust 构建，内存占用 < 50MB。对比 Electron 应用动辄 200MB+，真正的轻量级。

🔒

隐私优先

不收集任何用户数据，所有数据本地存储。AI 请求由用户自行配置 API Key，直接发送至 AI 服务商。

🔧

高度可定制

快捷方式、AI 后端、番茄钟时长均可配置。开源透明，欢迎提交 PR 扩展功能。
